# Early-Medicine-Recommendation-System
A Flask-based Early Health Care System that predicts diseases from                                             user                                                                         symptoms using a trained SVC machine learning model. It provides a simple web interface with authentication and shows predictions along with precautions, medications, diets, and workouts. Built using Python, Flask, and Scikit-learn.
